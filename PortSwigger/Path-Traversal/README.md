# Path Traversal

This directory contains writeups for completed PortSwigger Web Security Academy labs focused on file path traversal vulnerabilities.

## Completed Labs

1. [File path traversal: absolute path bypass](https://portswigger.net/web-security/file-path-traversal/lab-absolute-path-bypass)

## Key Learning Objectives

- Understanding file path traversal vulnerabilities.
- Learning how absolute file paths can affect path validation.
- Recognizing the risks of allowing user input to influence file access.
- Understanding the importance of validating file paths and restricting access to authorized directories.
