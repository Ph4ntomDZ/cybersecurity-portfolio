# Cross-Site Scripting (XSS)

This directory contains completed PortSwigger Web Security Academy labs focused on cross-site scripting vulnerabilities.

## Completed Labs

1. [Reflected XSS into HTML context with nothing encoded](https://portswigger.net/web-security/cross-site-scripting/reflected/lab-html-context-nothing-encoded)
2. [Stored XSS into HTML context with nothing encoded](https://portswigger.net/web-security/cross-site-scripting/stored/lab-html-context-nothing-encoded)
3. [DOM XSS in jQuery anchor href attribute sink using location.search source](https://portswigger.net/web-security/cross-site-scripting/dom-based/lab-jquery-href-attribute-sink)
4. [DOM XSS in document.write sink using source location.search](https://portswigger.net/web-security/cross-site-scripting/dom-based/lab-document-write-sink)

## Key Learning Objectives

- Understanding reflected and stored XSS.
- Identifying DOM-based XSS sources and sinks.
- Recognizing unsafe handling of user-controlled input.
- Understanding output encoding and safe DOM manipulation.
