# Information Disclosure

This directory contains writeups for completed labs from PortSwigger Web Security Academy focused on information disclosure vulnerabilities.

## Completed Labs

1. [Information disclosure in backup files](https://portswigger.net/web-security/information-disclosure/exploiting/lab-infoleak-via-backup-files)
2. [Information disclosure on debug page](https://portswigger.net/web-security/information-disclosure/exploiting/lab-infoleak-on-debug-page)
3. [Information disclosure in version control history](https://portswigger.net/web-security/information-disclosure/exploiting/lab-infoleak-in-version-control-history)
4. [Information disclosure in error messages](https://portswigger.net/web-security/information-disclosure/exploiting/lab-infoleak-in-error-messages)
5. [Information disclosure leading to authentication bypass](https://portswigger.net/web-security/information-disclosure/exploiting/lab-infoleak-authentication-bypass)

## Key Learning Objectives

- Identifying sensitive information exposed by web applications.
- Understanding risks associated with backup files and debug pages.
- Recognizing information leaks through version control history and error messages.
- Understanding how information disclosure can contribute to authentication bypass.
