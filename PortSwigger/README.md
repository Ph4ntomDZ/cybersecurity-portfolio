This directory contains my practical web application security lab writeups completed through PortSwigger Web Security Academy.

## Topics Studied

- Information Disclosure
- Access Control
- Path Traversal
- Cross-Site Scripting (XSS)

Additional topics will be added as I study and complete the corresponding labs.

## Completed Lab Categories

### 1. Information Disclosure — 5 Labs

- [Information Disclosure](Information-Disclosure/README.md)

Topics include backup files, debug pages, version control history, error messages, and authentication bypass.

### 2. Access Control — 5 Labs

- [Access Control](Access-Control/README.md)

Topics include user role manipulation, user ID manipulation, Insecure Direct Object References (IDOR), and authorization weaknesses.

### 3. Path Traversal — 6 Labs

- [Path Traversal](Path-Traversal/README.md)

Topics include absolute path bypasses, null byte bypasses, path validation, traversal sequence filtering, and URL decoding.

### 4. Cross-Site Scripting (XSS) — 4 Labs

- [Cross-Site Scripting](Cross-Site-Scripting/README.md)

Topics include reflected XSS, stored XSS, and DOM-based XSS.

## Lab Writeup Structure

Each individual lab report may include:

- **Lab Name:** Name of the lab
- **Objective:** What the lab requires
- **Vulnerability:** The vulnerability being investigated
- **Methodology:** Steps taken to analyze and solve the lab
- **Root Cause:** Why the vulnerability exists
- **Impact:** Potential security consequences
- **Mitigation:** How the vulnerability can be prevented
- **Key Takeaways:** What I learned
